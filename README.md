# دبّرني — نسخة العرض

تطبيق عربي لإدارة المصاريف والميزانية اليومية، مع واجهة React ونسخة Expo في مجلد `mobile`.

## تشغيل الموقع
يتطلب Node.js 22.13 أو أحدث.

```bash
npm ci
npm run dev
```
افتح http://localhost:3000 .

## تشغيل Expo Go
```bash
npm ci
npm --prefix mobile ci
npm run expo
```
امسح رمز QR باستخدام Expo Go المتوافق مع SDK 57. الهاتف والكمبيوتر على الشبكة نفسها.
الواجهة مضمّنة داخل التطبيق، والحفظ محلي على الجهاز. لا يوجد تزامن حسابات أو ربط بنكي.

## إصدار APK عبر EAS
من مجلد `mobile`:
```bash
npx eas-cli login
npx eas-cli init
npx eas-cli build --platform android --profile preview
```
استخدم حسابك لإنشاء وربط المشروع. لا تضع أي مفاتيح أو كلمات مرور في المستودع.
عند ربط GitHub من لوحة Expo اختَر مجلد التطبيق `mobile`.
أمر `eas-build-post-install` يبني واجهة الويب تلقائيًا أثناء البناء السحابي.

## التحقق
```bash
npm run lint
npm test
npm run build
npm run build:mobile
npm --prefix mobile run typecheck
cd mobile
npx expo export --platform android --platform ios
```

## ما يعمل في هذه النسخة
- إضافة المصروف وحذفه وتحديث الرصيد والحفظ المحلي.
- تعديل الرصيد والأيام المتبقية، وحساب ميزانية بعد الالتزامات.
- تقدير أثر شراء منتج حسب السعر الذي تدخله.
- اختيار صورة فاتورة ثم إدخال وتأكيد بياناتها يدويًا.

البيانات الأولية تجريبية. تحليل الفواتير الآلي غير مربوط في نسخة الجوال. الإدخال الصوتي يعتمد على دعم المتصفح؛ عند عدم توفره استخدم الكتابة. لا توجد نتائج ذكاء اصطناعي مختلقة عند غياب المفتاح.

خادم Express الاختياري يستخدم `GEMINI_API_KEY` في الخادم فقط. نسخة Expo الحالية لا تتصل بهذا الخادم.

## حالة التسليم
نجحت اختبارات الحسابات وبناء الويب وتصدير حزم iOS وAndroid. التصدير ليس APK موقّعًا؛ يلزم حساب Expo وبناء EAS وتجربة فعلية على جهاز قبل النشر.
